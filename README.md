# 🚀 Mi Proyecto Real - Frontend Base

Este es un proyecto real desarrollado para dominar la arquitectura limpia en React utilizando TypeScript.

## 🛠️ Stack Tecnológico Utilizado

- **React + TypeScript** (Vite)
- **Zustand:** Gestión de estado global eficiente y ligera.
- **TanStack React Query:** Sincronización y manejo del estado del servidor (Cache, Invalidation, Mutations).
- **React Hook Form + Zod:** Manejo optimizado de formularios y validación estricta de esquemas de datos.
- **React Router DOM:** Manejo de rutas complejas y layouts protegidos.
